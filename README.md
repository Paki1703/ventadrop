# VentaDrop rebuild v2
Обновлённый Next.js 16 + React 19 проект с новым дизайном.

## Возможности
- Адаптивная главная страница и анимация открытия кейсов.
- Демо-баланс в браузере (не деньги).
- Серверный API `/api/market` получает RUB-котировки Skinport и кэширует ответ на 5 минут; при недоступности показывает демо-данные.
- `/admin`: парольная серверная сессия и форма начисления демо-кредитов в Supabase.
- `supabase/schema.sql`: таблица профилей, журнал и атомарная RPC-функция начисления.

## GitHub / Vercel
1. Скачайте архив и распакуйте его.
2. В репозитории `Paki1703/ventadrop` удалите старые файлы и загрузите всё содержимое архива в корень (не сам ZIP).
3. Vercel должен определить Next.js автоматически. Используются Next.js 16.4.6 и React 19.3.1.
4. Дождитесь новой сборки.

## Skinport price feed
Публичный endpoint: `https://api.skinport.com/v1/items?app_id=730&currency=RUB&tradable=1`. Запрос выполняется на сервере и кэшируется 5 минут. У API есть rate limit; не делайте частые опросы. Цены — справочные листинги, а не гарантированная сумма продажи. Документация: https://docs.skinport.com/items

## Настройка админки
1. Создайте проект Supabase и выполните `supabase/schema.sql` в SQL Editor.
2. Создайте профиль в `public.profiles`, указав UUID пользователя.
3. В Vercel → Settings → Environment Variables задайте `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_PASSWORD`, `ADMIN_SESSION_SECRET` (длинная случайная строка).
4. Redeploy. Откройте `/admin`, войдите и укажите UUID, сумму и причину.
5. Начисления пишутся в `demo_balance_ledger`. Отрицательное значение списывает демо-кредиты.

## Границы прототипа
Кейсы, рулетка и баланс главной страницы демонстрационные. Админская SQL-таблица хранит только демо-кредиты; UI пока не синхронизирован с пользовательской авторизацией. Реальные платежи, продажа предметов, денежный вывод, Steam login/trade и реальная выдача предметов не подключены. Перед таким запуском необходимы отдельная авторизация, серверная система вероятностей и аудита, проверка требований законодательства и правил площадок.
