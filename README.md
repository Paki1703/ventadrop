# VentaDrop

Демонстрационный прототип сайта открытия кейсов в стиле CS2.

## Требования

- Node.js 20.9 или новее
- npm

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Публикация через GitHub

1. Создайте пустой репозиторий `ventadrop` на GitHub.
2. Распакуйте архив.
3. В терминале внутри папки проекта выполните:

```bash
git init
git add .
git commit -m "Initial VentaDrop prototype"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ventadrop.git
git push -u origin main
```

4. Для публикации подключите репозиторий к Vercel и нажмите Deploy.

## Важно

Это только фронтенд-прототип. Баланс виртуальный, результат открытия демонстрационный и формируется в браузере. Нет реальных платежей, реальной выдачи/продажи предметов, Steam-авторизации или серверной проверки случайности.

Перед запуском реальной экономики потребуется серверная реализация, защищённый журнал операций, проверяемые вероятности, антифрод, безопасная Steam-интеграция и юридическая проверка по целевым странам. Не храните Steam-пароли, Steam Guard-коды или секреты в GitHub.
